# 폰 센서 기반 영상 손떨림 보정 (EIS)

설계프로젝트1 · 모바일공학과 · 2022112595 장규영

## 한 줄 정의
폰의 자이로 센서와 카메라 타이밍을 이용해 영상 손떨림 보정(EIS)을 직접 구현하고, 갤럭시 기본 안정화를 기준으로 정량 비교·분석하는 프로젝트.

## 문제
손으로 들고 찍으면 폰이 미세하게 흔들려 영상 품질이 떨어진다. 폰은 OIS(렌즈를 물리적으로 움직임)와 EIS(소프트웨어 보정)로 이를 줄이지만, 안정화 강도에는 딜레마가 있다. 세게 걸면 흔들림은 사라지지만 일부러 카메라를 돌리는 동작(패닝)까지 뭉개져 화면이 늦게 따라오고 더 많이 잘리고, 약하게 걸면 흔들림이 남는다.

## 기본 원리
영상을 찍으면서 자이로(폰이 얼마나 돌았는지 재는 센서) 값을 함께 기록해 프레임마다 카메라의 회전을 계산하고, 그만큼 화면을 반대로 돌려 다시 그린다. 자이로 기반 안정화 자체는 이미 알려진 기법이며, 이 기본 구현 위에 최적화를 얹고 조건별 효과를 직접 측정하는 것이 이 프로젝트의 기여다.

## 품질을 좌우하는 하드웨어 조건 2가지
1. **시계 맞추기** — 영상과 자이로가 각자 다른 시계로 시각을 기록해, 몇 ms만 어긋나도 엉뚱한 타이밍에 보정이 걸린다.
2. **롤링 셔터** — 카메라가 화면을 위에서 아래로 한 줄씩 읽어, 한 프레임 안에서도 줄마다 촬영 시각이 다르다. 줄별로 보정해야 영상이 휘지 않는다.

## 이번에 시도하는 것 (최적화)
자이로 신호에서 특징(크기, 주된 주파수, 지속 시간)을 뽑아 작은 분류기(딥러닝 아님, 결정 트리/로지스틱 회귀 수준)를 학습시켜 손떨림·걷기·패닝을 구분하고, 상황에 맞춰 안정화 강도를 자동 조절한다. 갤럭시 기본 안정화는 비교 기준으로 삼아 고정 강도보다 얼마나 나아지는지와 갤럭시와 어디서 차이 나는지를 수치로 확인한다.

## 시스템 구조
촬영·기록(Camera2 + SensorManager) → 회전 계산 → 시간 맞추기 → 상황 판단(분류기) → 강도 조절 → 다시 그리기.
폰 앱(Kotlin)은 데이터 수집용이고, 보정 처리와 분류기 학습은 PC(Python · OpenCV · scikit-learn)에서 오프라인으로 한다.

## 검증
A(무보정) / B(갤럭시 기본, 별도 촬영 후 평균 비교) / C(고정 강도) / D(적응형)를 비교한다.
재는 것: 안정도, 패닝 반응 지연, 잘려나간 화면 비율, 상황 구분 정확도, 자이로 측정 주기별 배터리 소모.
제자리·걷기·패닝을 각 5회 촬영해 평균과 편차로 비교한다.

## 결과물
1. 영상+자이로 동시 기록 앱 (Android)
2. 안정화 프로그램 (고정 강도 → 적응형)
3. 네 조건 비교표·그래프
4. 분석 보고서 (개선점과 한계 정리)

**최소 목표**: 기록 앱 + 기본 안정화 + 무보정·갤럭시와의 비교까지. 적응형과 확장은 시간이 되는 만큼 진행한다.

## 아직 검증 전인 것 (초반 확인 대상)
- 카메라와 자이로의 시간 정렬이 가능한지
- 카메라 자체 손떨림 보정(OIS)을 끌 수 있는지, 이중 보정 여부
- 고속 자이로 샘플링이 가능한지

## 알려진 한계
- 기본 원리(자이로 기반 안정화)는 새로운 기법이 아니라 이미 연구된 기법이다.
- 상황 구분 분류기는 단순 모델이며 딥러닝이 아니다.
- 갤럭시 기본 안정화(B)와의 비교는 촬영 방식 차이로 완전히 공정하지 않다.
- 촬영자 본인 한 명의 데이터로만 검증해 일반화는 어렵다.
- 핵심 보정 계산은 폰이 아닌 PC에서 오프라인으로 수행한다 (여유 시 폰 실행으로 확장).
